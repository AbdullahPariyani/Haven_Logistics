# Haven Logistics

International air, sea, and land freight services from Jeddah, Saudi Arabia.

**Live website: https://abdullahpariyani.github.io/Haven_Logistics/**

[![Haven Logistics website](docs/screenshot.jpg)](https://abdullahpariyani.github.io/Haven_Logistics/)

## Development

```bash
npm install
npm run dev
```

## Deployment

Every push to `main` builds the site and publishes it to GitHub Pages via
[.github/workflows/deploy.yml](.github/workflows/deploy.yml).
